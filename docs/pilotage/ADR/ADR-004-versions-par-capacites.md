# ADR-004 — Versions par capacités mesurables

**Statut** : rétro-documenté (décision implicite antérieure au 17 juillet 2026)

## Contexte

La trajectoire initiale était calendaire, avec des jalons datés.

## Décision

**Aucune date** : chaque version est définie par des **critères d'entrée
et de sortie mesurables**.

## Alternatives rejetées

- **Roadmap calendaire** : dates arbitraires en solo, jalons non
  falsifiables.

## Conséquences

- Le passage de version est un constat de capacités, pas une échéance.
