# ADR-012 — Versions par capacités mesurables

**Statut** : rétro-documenté (décision implicite antérieure au chantier 4)

## Contexte

La trajectoire initiale (`ROADMAP.md`, archivé) était calendaire, avec
des jalons datés.

## Décision

**Aucune date** : chaque version est définie par des **critères d'entrée
et de sortie mesurables**. v0 = « mesurable » (data + éval, **sans**
applicatif).

## Alternatives rejetées

- **Roadmap calendaire** (`ROADMAP.md`) : dates arbitraires en solo,
  jalons non falsifiables.

## Conséquences

- `VERSIONS.md` remplace la roadmap ; le passage de version est un
  constat de capacités, pas une échéance.
